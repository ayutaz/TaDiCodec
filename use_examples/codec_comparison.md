### コンテキストウィンドウへの影響

GPTのようなLLMで音声を扱う場合、トークン数が重要です。

**例：10秒の音声を処理する場合**

| システム | トークン数 | GPT-4での使用 |
|---------|-----------|--------------|
| **TaDiCodec** | **約62トークン** | ✅ 非常に効率的 |

| MaskGCT | 約4000トークン | ❌ 大量のコンテキスト消費 |

**実用例：会話AI**

```

TaDiCodec:
→ 入力62 + 出力62 = 124トークン

VALL-E:
→ 入力1000 + 出力1000 = 2000トークン

```

## 2つのTTS手法の提供

### AR-TTS（自己回帰型）

**特徴:**
- 高品質な音声生成
- LLM（Qwen2.5またはPhi-3）を使用
- トークンを1つずつ順次生成

**モデル選択肢:**
1. `Qwen2.5-0.5B` - 軽量・高速
2. `Qwen2.5-3B` - 高品質（推奨）
3. `Phi-3.5-4B` - 最高品質

### MGM-TTS（マスク生成モデル）

**特徴:**
- AR-TTSより高速（並列生成）
- MaskGCTベースの拡散モデル
- 品質とスピードのバランスが良い

**速度比較:**
```
AR-TTS (Qwen2.5-3B):  1秒の音声生成に約5-10秒
MGM-TTS:              1秒の音声生成に約2-5秒
```

## クロスリンガル能力

他の多くのTTSは単一言語または限定的な多言語対応ですが、TaDiCodecは：

**✅ 英語プロンプト → 日本語生成が可能**

```python
# 英語の音声サンプルを使って
prompt_audio = "trump_0.wav"  # 英語音声
prompt_text = "In short, we embarked..."  # 英語テキスト

# 日本語を生成
output = pipeline(
    text="こんにちは、これは日本語の音声です。",
    prompt_speech_path=prompt_audio,
    prompt_text=prompt_text,
)
```

**実際にテスト済み:**
- 英語 → 日本語 ✅
- 英語 → 中国語 ✅
- 日本語・英語の混在（コードスイッチング）✅

## コードスイッチング対応

自然な多言語混在も可能：

```python
text = "但是 to those who 知道 her well, it was a 标志 of her unwavering 决心 and spirit."
```
